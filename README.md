# 가계부 · Money Desk

개인 · 편의점 · 풍월관의 지출, 편의점 월매출, 토토 수수료를 관리하는 개인 장부입니다. 공개 소스에는 금융 내역이나 비밀번호가 들어 있지 않습니다.

## 사용 흐름

- **전체 요약:** 확정 수입·지출·장부 수지, 사용처·결제수단·월별 흐름
- **거래 입력:** 날짜·금액·거래처로 등록하고 선택 사항에서 분류·결제수단·메모 지정
- **전체 거래내역:** 기간·사용처·결제수단·검색 필터, 미분류·제외 내역 조회와 복원
- **여러 건 입력:** 엑셀 붙여넣기와 키보드 이동, 탭 내 초안 보관
- **매출 관리:** 편의점 월 총매출·참고 순이익, 토토 일별 판매액·수수료와 월 확정액
- **가져오기·분류:** 뱅크샐러드 XLSX 미리보기, 기존 JSON 안전 병합, 개인·편의점·풍월관 3버튼 분류
- **환불 관리:** 환불일의 별도 거래로 표시해 그 기간의 순지출에서 차감. 원결제 연결·해제와 집계 제외·복원 지원
- **저장·백업:** 브라우저 자동 저장, 로그인한 서버와 동기화, JSON 전체 백업 및 CSV 내보내기

모바일에서는 하단 빠른 메뉴와 카드형 거래내역을 제공합니다. V1 화면·전용 스크립트·스타일·진입 링크는 제거했습니다. 기존 브라우저 자료와 시트 JSON을 복구하기 위한 호환 읽기만 유지합니다.

## 저장

`localStorage['gagebu-v2-private']`에 먼저 저장합니다. 브라우저 저장 실패 시 마지막 저장본으로 되돌리며, 잘못된 날짜·금액·백업 설정은 저장 전에 거부합니다. 과거 `gagebu-v1-data`는 호환 읽기만 하며 삭제하지 않습니다.

서버 연결 전에는 **이 브라우저에 저장됨**으로 표시합니다. D1과 Worker를 실제로 배포하고 **저장·백업**에서 API 주소·비밀번호로 로그인해야 서버 동기화가 작동합니다. **서버 저장 확인됨**이 표시되어야 해당 변경이 서버에 저장된 것입니다. 배포 코드가 준비된 것만으로 서버 연결 완료를 의미하지 않습니다.

비밀번호는 브라우저에 저장하지 않습니다. 12시간짜리 세션은 현재 탭에만 보관합니다. 서버 저장은 버전을 비교해 충돌 시 중단하고, 사용자가 자료를 선택할 때 덮어쓸 쪽을 JSON으로 백업합니다. D1에는 최근 10개 문서 버전을 유지합니다.

은행 엑셀 원본은 브라우저에서만 분석합니다. 서버 동기화에는 분석·분류 후의 장부 자료가 전송됩니다. 백업이나 금융 엑셀을 공개 저장소·배포 폴더에 넣지 마세요.

## 계산 기준

- 편의점 월 총매출과 토토 월 확정 수수료를 수입으로 계산합니다. 참고용 순이익·토토 판매액·일별 수수료는 중복 합산하지 않습니다.
- 분류 완료한 지출만 확정 수지에 반영합니다. 미분류와 제외 거래는 별도로 표시합니다.
- 환불은 원결제 연결 여부와 관계없이 실제 환불일이 속한 달의 순지출에서 한 번 차감합니다. 원결제 금액과 환불 기록을 모두 보존하며, 연결은 대조용입니다. 원결제 미상 환불도 전체 순지출에 반영하고, 사용처는 미지정으로 표시합니다. 집계 제외한 환불은 차감하지 않습니다.
- 은행 간 이체·카드대금·온누리 충전·투자·토토 운영대금은 중복 지출에서 제외합니다. 온누리는 사용액만 지출로 계산합니다.
- 기존 현금 매입은 외부 금융내역에서 발견되지 않아도 유지합니다. 오래된 JSON은 없는 거래만 추가하며 현재 수정 내용을 덮어쓰지 않습니다.

## 검증·정적 빌드

Node.js 22.13 이상:

```bash
npm test
npm run build
```

`dist/`에는 허용한 화면 파일과 로컬 JSZip 라이브러리만 복사합니다. 배포 출력 폴더는 `dist`이며 서버·테스트·개인 자료는 포함하지 않습니다. 금융 자료나 서버 비밀번호를 정적 화면에 주입하지 마세요.

## Cloudflare 서버 배포

`.github/workflows/deploy-cloudflare.yml`은 수동 실행으로 전용 D1 생성·재사용, 스키마 준비, Worker 배포를 처리합니다. 기존 테이블이나 장부는 삭제하지 않습니다. 먼저 저장소 Actions secrets에 다음 항목을 설정하세요.

| 이름 | 용도 |
| --- | --- |
| `CLOUDFLARE_ACCOUNT_ID` | 배포할 Cloudflare 계정 |
| `CLOUDFLARE_API_TOKEN` | 해당 계정의 D1·Worker 배포 권한 |
| `STORE_LEDGER_ADMIN_PASSWORD` | 가계부 로그인 비밀번호, 8자 이상 |
| `STORE_LEDGER_SESSION_PEPPER` | 세션 해시용 임의 비밀값, 32자 이상 |

`wrangler.toml.example`을 바탕으로 로컬 설정을 만들 수도 있습니다. `db/schema.sql`은 `CREATE TABLE IF NOT EXISTS`와 `INSERT OR IGNORE`만 사용합니다. Worker의 `/health`와 로그인 후 V2 저장·다시 읽기까지 검증한 후 서버 연결 완료로 안내하세요.
